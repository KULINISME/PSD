# Welcome to My Project Science Data
Selamat Datang!

Selamat datang di repositori proyek Sains Data saya. Proyek ini merupakan perjalanan eksplorasi data untuk menjawab satu pertanyaan sederhana namun penting: seberapa sehat udara yang kita hirup setiap hari?

Melalui data citra satelit Sentinel-5P, proyek ini mengumpulkan, membersihkan, dan menganalisis konsentrasi tiga polutan udara utama — NO2 (Nitrogen Dioksida), CO (Karbon Monoksida), dan SO2 (Sulfur Dioksida) — di wilayah Jombang, Jawa Timur, selama satu tahun penuh.
